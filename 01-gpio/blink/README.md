## Objective

## Hardware
- MCU: STM32F401RE
- Board: Nucleo-F401RE
- Onboard LED: LD2
- GPIO Pin: PA5

## Concepts
- GPIO peripheral
- RCC peripheral clock enable
- GPIO mode configuration
- Output data register
- Register-level programming

## Implementation
Describe how the GPIO clock is enabled, PA5 is configured as output, and the LED is controlled.

## Expected Result
The onboard LED blinks continuously.
